# Run the exercise

1. From the repository root, open the project:

   ```sh
   open lab.ios.WebView.xcodeproj
   ```

2. In Xcode, select the `lab.ios.WebView` scheme.
3. Select an installed iPhone Simulator running iOS 17 or newer.
4. Keep network access enabled for the Simulator and run the app with `⌘R`.
5. Run the included tests with `⌘U`.
